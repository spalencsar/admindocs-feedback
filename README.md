# Admin:Docs – Feedback

Dieses Repository ist der öffentliche Feedback-Kanal für [Admin:Docs](https://admindocs.de). Hier kannst du Fehler, veraltete Angaben und Verbesserungsvorschläge zu veröffentlichten Inhalten melden.

## So hilfst du

1. Prüfe kurz, ob bereits ein passendes Issue existiert.
2. Wähle beim Erstellen eines Issues die passende Vorlage.
3. Nenne den Link zum betroffenen Artikel, eine konkrete Beschreibung und – wenn möglich – eine Quelle oder einen reproduzierbaren Nachweis.

## Bitte beachten

- Dieses Repository enthält bewusst keinen Quellcode und keine Deploy-Konfiguration der Website.
- Bitte veröffentliche keine Zugangsdaten, personenbezogenen Daten oder vertraulichen Informationen.
- Sicherheitsrelevante Hinweise gehören nicht in ein öffentliches Issue. Nutze dafür bitte die Kontaktmöglichkeit im Impressum von Admin:Docs.

Vielen Dank, dass du Admin:Docs aktuell und korrekt hältst.
